# foxia-studio-releases
Bản cài Fox Studio (macOS / Windows)


## Cài đặt
- **macOS** (Apple Silicon + Intel): mở `FoxStudio_0.1.1_universal.dmg`, kéo Fox Studio vào Applications.
- **Windows**: chạy `FoxStudio_0.1.1_x64-setup.exe`. Nếu SmartScreen cảnh báo, bấm "More info" → "Run anyway".
Lần đầu xuất video, app tự tải Chrome headless (~100 MB) nên cần mạng.
